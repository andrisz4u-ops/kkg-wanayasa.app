# Audit 019: Sidebar fitur unggulan

Mode: AFTER. Tanggal: 4 Oktober 2026.

Lingkup: daftar sidebar per peran, penyederhanaan kontrolnya dan penyesuaian tinggi desktop/rail. Arah visual Studio Hijau Organik, ENERGY 3 / RHYTHM 3 / MOTION 2.

## Temuan

Tidak ada temuan baru dalam lingkup perubahan setelah verifikasi.

## Alasan desain

- Satu kelompok Fitur unggulan mengikuti daftar pekerjaan utama yang ditentukan pengguna, bukan pengulangan seluruh navigasi header (R-05, R-31).
- Enam tujuan Guru dan delapan tujuan pengelola mengurangi kepadatan; urutan konsisten membantu pemindaian (R-20, R-31).
- Penghapusan kolom pencarian memberi ruang vertikal karena daftar tujuan kini pendek dan langsung terlihat (C-3, R-31).
- Skala logo dan jarak lebih rapat pada laptop pendek membuat semua tujuan tetap terjangkau dengan tombol minimal 44 px (R-03).
- Hutan dan mint mengikuti identitas serta menandai halaman aktif; fokus mint 3 px menunjukkan posisi keyboard (R-01, R-25, R-32).

## Bukti verifikasi

- `npm run build`: lulus.
- `npx vitest run tests/workspace-navigation.test.ts tests/educator-workspace.test.ts tests/feature-design.test.ts tests/feature-composition.test.ts tests/ui-refinement.test.ts`: 58 tes lulus dalam 5 berkas.
- `git diff --check`: lulus.
- Browser lokal menggunakan sesi terisolasi, pengguna sementara di memori dan respons GET untuk pengujian tampilan. Permintaan perubahan data diblokir dalam sesi pengujian.
- Ukuran 1366 x 768: Guru, Operator, Admin dan Super admin, masing-masing mode lebar dan ringkas. Semua tujuan terlihat; selisih `scrollHeight - clientHeight` navigasi maupun sidebar 0; overflow horizontal 0.
- Ukuran 1280 x 650: empat peran, dua mode sidebar, dua tema, 16 kombinasi lulus. Semua tujuan terlihat tanpa gulir; tinggi tombol 44 px pada mode lebar dan 45 px pada rail.
- Axe pada sidebar: 0 pelanggaran terkonfirmasi, 13 pemeriksaan lulus, satu pemeriksaan kontras latar gradasi membutuhkan tinjauan manual. Kontras konservatif terhadap ujung gradasi paling terang: teks menu 9,14:1, teks pendukung 6,52:1, penanda aktif 9,82:1.
- Tab lalu fokus Asesmen menunjukkan outline mint solid 3 px; Enter membuka `kisi` dan penanda aktif menjadi Asesmen.
- Ponsel 390 x 844: overflow horizontal 0; drawer membuka navigasi lengkap dan menyediakan Forum; Escape menutup drawer, melepas inert dan mengembalikan fokus ke pemicu menu.
- Tidak ada error atau unhandled rejection baru dalam sesi browser.

## Delivery Gate

- Hard Gate PASS: seluruh tujuan memiliki aksi nyata; izin, fokus, kontras, tema dan ukuran tombol diverifikasi. Tidak ada aset, angka promosi, klaim atau konten rekaan baru (R-02, R-03, R-17, R-18, R-23 sampai R-28, R-32 sampai R-38).
- Purpose-Gate PASS: warna, logo, ikon dan gerak mengikuti Studio Hijau Organik; penyederhanaan kelompok dan skala mempunyai alasan tertulis (R-01, R-04, R-06 sampai R-14, R-19, R-22, R-31).
- Liveliness PASS: sidebar mempertahankan identitas hutan/mint dan medali logo; halaman aktif menjadi fokus, sementara pengurangan daftar memberi ruang struktural sesuai kebutuhan pengguna.
- Craftsmanship dan Quality Locks PASS: susunan mengikuti pekerjaan utama per peran, tombol tetap minimal 44 px, tujuan nyata dan alur header/drawer berfungsi; bukti build, tes dan browser tercatat (C-1 sampai C-5, R-05, R-11, R-15, R-16, R-20, R-21, R-29 sampai R-31).
