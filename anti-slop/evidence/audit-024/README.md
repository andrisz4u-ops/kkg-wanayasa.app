# Bukti Studio Kelas Hidup

Pemeriksaan menggunakan browser lokal pada desktop, tablet dan ponsel. Identitas guru dan respons AI dalam pengujian adalah fixture sementara yang diberi label contoh; tidak mengirim permintaan ke provider AI atau menulis akun/database. Contoh Matematika, IPAS dan Bahasa Indonesia dipakai untuk memeriksa hasil, diagram, kuis, presenter dan ekspor. Penyimpanan contoh hanya berada pada profil browser pemeriksaan.

Pemeriksaan struktur otomatis tidak membuktikan seluruh materi AI selalu benar. Guru meninjau materi sebelum menggunakannya di kelas.
