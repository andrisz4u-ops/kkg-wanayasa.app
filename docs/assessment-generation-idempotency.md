# Assessment generation idempotency ledger

Migration `0043_assessment_generation_requests.sql` adds an owner-scoped request ledger keyed by `(owner_id, client_document_id)`. Apply it using the repository's normal reviewed migration process; this helper does not apply migrations at runtime.

The semantic request hash is SHA-256 over deterministic JSON with object keys sorted and an explicit schema version of `1`. The caller must pass already normalized semantic input. Undefined values and non-JSON values are rejected rather than silently omitted. The primary-key insert is the acquisition boundary: only its winner receives a run token. Same-input retries observe running/completed/ended state; they do not take over stale work. Failed and cancelled identities remain reserved. Start a new client document ID to intentionally retry an ended generation.

Both `POST /api/kisi/generate` and `POST /api/kisi/generate-stream` authenticate, stream-read a bounded JSON body (1 MiB maximum with the shared depth guard), validate it, and reserve the ledger identity before AI admission or provider work. A missing `clientDocumentId` is replaced with a server UUID and returned in the result. The semantic identity omits that ID and transport-specific SSE job information. Exactly one reservation winner proceeds to admission/provider execution; completed requests replay the current owner- and document-qualified package revision (or the cached failed-save content) without another admission or provider call. A missing, mismatched, or non-completed identity sent with `X-Assessment-Replay-Only: 1` returns a conflict and never reserves a ledger row. Normal requests with conflicting input, running work, or ended identities return conflict without retry/takeover. A cached response from the separate legacy SSE-job table is never treated as an assessment result: if the new ledger winner encounters any existing job identity, the reservation ends and the request receives a conflict.

Completion is fenced by owner, document ID, run token, and running state. Its input is a discriminated contract: either `{ packageId: positiveSafeInteger }` for a saved package, or `{ result: recoveryAssessment }` when package persistence failed. Recovery must be a plain assessment object with `_persistence.saveStatus === 'failed'` and at least one nonempty actual question row in `pg`, `isian.data`, or `uraian`; each retained question row must have a nonempty `soal`, `pertanyaan`, or `question` string. Empty objects, null results, and invalid package IDs cannot complete a request. The decoder enforces the same invariant for completed database rows; a positive package ID permits a JSON `null` result. Result JSON is limited to 1 MiB UTF-8; callers must provide normalized safe content. The optional AI job fence additionally checks the matching owner/job, running state, and lease against SQLite's current Unix time. Cancellation/failure deliberately uses the request fence only, so it can terminate after the job itself has stopped. The helper does not log request or result bodies and does not replay legacy stream-job results.

On a successful save, the package helper atomically commits the package, associations, ledger completion pointer, and write receipt. Partial-generation metadata is attached before persistence and ledger completion, so the package or failed-save recovery value has the same `_generation` contract as the original response and both replay transports. SSE replay derives its top-level `partial` and `warnings` from that persisted metadata. If image normalization yields usable content but package persistence fails, the normalized content is cached with failed-save metadata; failed normalization is not cached as recovery. Fenced conflicts and failure to settle recovery are errors, not successful generation responses. SSE creates its stream job only after ledger reservation and admission; early stream setup failures settle the ledger rather than triggering an automatic second generation. An admission-storage exception after reservation also ends that reservation through the route error path.
