# Prompt preview dashboard RuangKKG

Tanggal: 2 Oktober 2026. Dibuat menggunakan imagegen bawaan. Teks berikut adalah instruksi pembuatan gambar, bukan prompt generator RPP atau Analisis CP aplikasi.

## Prompt bersama

Use case: ui-mockup.
Create ONE high-fidelity desktop screenshot concept for the logged-in home dashboard of the Indonesian educator application "RuangKKG Digital". Wide landscape canvas, approximately 1600 x 1000, full interface edge-to-edge, flat front-on screenshot, crisp readable Indonesian text. It must feel like a carefully designed, realistically buildable productivity workspace, elegant and contemporary, with expressive proportions and comfortable readability for teachers. This is a concept preview, not a marketing landing page.
Page's job: let a teacher start RPP or Analisis CP, resume saved teaching documents, and see KKG activities. Keep the content focused and meaningful, with a single visual focal point and ample but structural whitespace. No giant empty placeholder panel.
Use existing routes/features only: "Beranda", "Perangkat ajar", "Komunitas", "Agenda", "Pengumuman"; profile "Guru" with initials "GU", small notification bell. Text-only brand "RuangKKG Digital", a small teal brand dot if necessary, no new elaborate logo.
Main greeting exact text: "Selamat datang, Guru". Supporting text: "Siapkan pembelajaran dan lanjutkan pekerjaan Anda."
Primary existing action "Buat RPP", short helper "Rencana dan modul ajar". Prominent second action "Analisis CP", helper "CP, TP, ATP dan perangkat ajar". Existing secondary actions "Buat asesmen", "Buat slide", "Presensi". Existing community links "Bank materi", "Forum diskusi", "Game edukasi".
Show the section "Dokumen terakhir" with THREE sample saved documents only: "Pecahan sederhana" with "RPP · Matematika · Kelas V"; "Ekosistem" with "Asesmen · IPAS · Kelas V"; "Tata surya" with "Slide · IPAS · Kelas VI". Each has a document-relevant icon, a tidy date such as "1 Okt 2026", and an obvious "Buka" action. Use real text, not skeleton bars or gibberish. Small storage note exact text "Tersimpan di perangkat ini."
Include compact "Agenda KKG" with one sample item "Diskusi perangkat ajar", "5 Okt · 13.00", and "Pengumuman" with sample "Persiapan pertemuan KKG", and a clear "Buka kalender" link. All sample content must be transparently labelled at the bottom with exact text "Preview desain · Data contoh".
Constraints: only UI appearance; no AI-generated document output shown as actual output, no proposed changes to RPP or CP content, no invented functionality, no analytics charts, no usage numbers, no ratings, no testimonials, no fake security badges, no search bar or global archive button, no payment/pricing, no promotional copy. No device frames, floating desktop computers, browser address bar, angled perspective, collage of multiple dashboards, or external brand logos. No cartoon people, 3D objects, neon glow, star/sparkle/magic icons, blue-purple gradient, ornamental grid background, or tiny unreadable text. Use semantically relevant document/calendar/community symbols consistently. Make the layout calm yet visibly crafted rather than stiff admin boxes.

## 01. Soft Monochrome

STYLE 1: SOFT MONOCHROME. This is the soft, elegant successor to a rigid white/graphite interface. Palette: porcelain #FAFBFC, paper #FFFFFF, graphite #242A30, silver #E5E9ED, restrained teal #176F69. Type: graceful modern humanist sans in the character of Avenir for headings, Source Sans 3 for body; medium weights, no oversized ultra-bold heading. Layout: slim top navigation, comfortable horizontal welcome; underneath a SINGLE elongated graphite RPP action band that includes a quieter CP link in its right area, giving a clear main focal point. Main body 70% document list on the left, 30% agenda and announcements on the right. Documents use spacious editorial rows with soft thumbnail corners, NOT a grid of bordered cards. Secondary tools are a low unobtrusive horizontal strip under the documents. Signature: elegantly staggered paper-edge thumbnails plus a very restrained 16px radius on the main work surface, fine inner separation and soft selective elevation. Keep most surfaces flat, avoid border around every section. Refined asymmetry and subtle material depth, not huge empty gaps. Energy 2 / rhythm 2 / motion 1.

Energy 2 / rhythm 2 / motion 1.

## 05. Paper Studio

STYLE 5: PAPER STUDIO. A refined editorial document studio for teachers, distinctive typographic elegance and less software-dashboard rigidity. Palette: clean paper #FFFFFF, light zinc #F2F3F5, ink #2C2834, muted slate #595866, restrained deep teal #176F69. Use a beautifully controlled Lora serif ONLY for the greeting and document-section headline (roughly 34px), with highly legible Work Sans for ALL navigation, body, buttons and document titles. No cream canvas, terracotta, newspaper dense columns, tiny hairline-only grid, or ornate luxury branding. Layout clearly DIFFERENT: compact top navigation; a generous serif greeting on the upper left and a tiny practical agenda strip on upper right. Main work area has a narrow LEFT 'Perangkat ajar' shelf (about 290px) with a prominent deep-teal RPP button, an elegant CP block beneath, and supporting tools as calm text rows. On the RIGHT the primary 'Dokumen terakhir' worktable occupies 65% of the width: three roomy row entries, authentic paper-like small thumbnails, title/type/class/date, and Buka on the right. Documents sit in ONE continuous white work surface with selective light bottom rules, no tile mosaic. Below the worktable put one quiet announcement line and community links. Signature: the large literary welcome balanced with a precise sans-serif teaching-document worktable; white paper and restrained typography convey the subject. More human and elegant, no rigid admin boxes, no ornamental illustrations, no fake charts. Energy 2 / rhythm 3 / motion 1.
