# Audit antislop 015 — kartu generator

Tanggal: 4 Oktober 2026. Mode: AFTER, sesuai pilihan pengguna. Cakupan: formulir RPP, Asesmen, dan Analisis CP setelah disusun menjadi tiga kartu. Arah visual berasal dari `DESIGN.md`; spesifikasi susunan dan alasan keputusan dicatat di `docs/superpowers/specs/2026-10-04-compact-generator-cards-design.md`.

## Temuan yang memerlukan persetujuan

1. **HIGH, R-32 / R-26 — area unggah PDF Analisis CP hanya bisa dibuka lewat klik.** `#pdf-dropzone` pada `public/static/js/pages/analisis-cp.js` berupa `div` dengan pendengar `click`, sedangkan `#pdf-file-input` disembunyikan. Saat memakai Tab, pengguna keyboard tidak dapat memicu pemilih PDF. Area ini sudah ada sebelum perubahan kartu; perlu kontrol berfokus keyboard yang dapat membuka input berkas. **Belum diubah; tunggu persetujuan pengguna untuk temuan 1.**

## Hasil pemeriksaan ruang lingkup

- RPP, Asesmen, dan Analisis CP masing-masing menampilkan tiga kartu pada lebar 1440 piksel. Pada 820 piksel kisi menjadi dua kolom; kartu ketiga mengambil satu baris. Pada 390 piksel kartu menjadi satu kolom, tanpa limpahan mendatar. Pilihan mata pelajaran dan target semester CP disusun vertikal pada ponsel supaya lebih mudah dibaca.
- Elemen asli tidak diganti. Pengujian 35 kasus lulus pada `feature-composition`, `feature-design`, dan `ui-refinement`. `npm run build` berhasil. `git diff --check` tidak menemukan kesalahan whitespace pada perubahan terlacak.
- Klik di browser lokal: tambah pertemuan RPP mengubah `1P` menjadi `2P`; tag profil lulusan beralih aktif; tambah PG Asesmen mengubah `10` menjadi `11`; tab Teks CP membuka panel teks dan menutup PDF; Tambah Bab CP menambah entri; tombol CP tetap berada dalam kartu Review. Form RPP kosong gagal validasi HTML. Browser tidak melaporkan galat halaman saat sesi ini.
- Mode gelap diperiksa pada Analisis CP dan Asesmen di ponsel: permukaan, teks dan grid tetap terbaca; tidak ada overflow. Pemeriksaan dibuat menggunakan render modul lokal di sesi browser terisolasi karena halaman fitur meminta login. Panggilan generasi AI, unggah berkas, dan ekspor dokumen tidak dijalankan pada sesi uji ini.

## Alasan visual

Kartu mengikuti alur identitas, materi, lalu pengaturan/hasil review. Bidang putih tanpa bayangan berlebihan membuat isian mudah dipindai; hijau hutan menjadi jangkar ruang kerja, sedangkan satu garis hijau pada kartu utama menandai prioritas tanpa dekorasi berulang. Tipografi Georgia pada judul mengingatkan pada dokumen ajar; isian tetap menggunakan sans. Jarak ringkas meminimalkan gulir, dan tombol ponsel mempertahankan target sentuh 44 piksel.
