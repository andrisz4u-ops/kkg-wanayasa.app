# Rencana implementasi ruang kerja

- [x] Tinjau beranda, shell, endpoint komunitas, dan mekanisme arsip lokal.
- [x] Tetapkan arah desain sesuai persetujuan pengguna.
- [x] Buat renderer beranda dengan akses utama, dokumen terakhir, agenda, pengumuman, dan komunitas.
- [x] Terapkan shell/sidebar/header dan navigasi mobile yang konsisten.
- [x] Hubungkan pemulihan arsip dengan modul asalnya.
- [x] Jalankan pengujian perilaku, sintaks, dan build.
- [x] Periksa tampilan desktop/mobile dan jalur interaksi di browser.
- [x] Audit antislop setelah implementasi, sesuai pilihan pengguna.

Validasi: 14 pengujian terkait dashboard/arsip lulus; sintaks modul dan build berhasil. Pemeriksaan browser mencakup akun admin dan guru, layar 375/390/768 px serta desktop, pintasan fitur, menu akun, notifikasi, menu ponsel, dan fokus keyboard. Operator/super admin diperiksa melalui pengujian peran. Riwayat dokumen memakai penyimpanan per akun di perangkat yang bersangkutan.
